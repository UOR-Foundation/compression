uorc

Universal Object Reference Compression. Each archive is an exact executable object reference that this page decodes and verifies in your browser through WebAssembly. Nothing is uploaded.

Use it

Command line

uorc compress --stats notes.txt      # writes notes.txt.uorc
uorc decompress notes.txt.uorc -o notes.restored.txt
cat data.bin | uorc compress - > data.uorc

Rust library

let archive = uorc::compress(&bytes, uorc::DEFAULT_STEPS)?;
let original = uorc::decompress(&archive, uorc::DEFAULT_DECODE_WORK)?;
assert_eq!(original, bytes);

JavaScript (this page's module)

import { load } from "./uorc.js";
const uorc = await load("./uorc.wasm");
const archive = uorc.compress(new TextEncoder().encode("hello hello hello"));
const original = uorc.decompress(archive);

Binaries, the library source bundle and this WebAssembly module are attached to each GitHub release. Benchmark results for the release are on the benchmarks page.
