uorc

Universal Object Reference Compression. Each archive is an exact executable object reference that this page decodes and verifies in your browser through WebAssembly. Nothing is uploaded.

Try it

Several files or a folder become one archive of ordered objects: a manifest
  of relative paths, then each file. Decompressing it lists every file for
  download. Inspect reads the frame header and checks the integrity seal without
  decoding; Verify decodes in memory and, given an original, compares the bytes.

Use it

  
Command line


uorc compress --stats notes.txt      # writes notes.txt.uorc
uorc decompress notes.txt.uorc -o notes.restored.txt
cat data.bin | uorc compress - > data.uorc   # any size: streams through 8 MiB frames
uorc compress --threads 4 big.tar     # frames compress in parallel
uorc compress photos/                 # writes photos.uorc (a whole tree)
uorc decompress photos.uorc -o restore/   # --resume finishes an interrupted restore
uorc inspect notes.txt.uorc           # header and integrity, no decoding
uorc verify notes.txt.uorc notes.txt  # decode, check, compare

  
Outputs are written to a temporary file and renamed into place; an existing
  file is only replaced with --force. Exit status: 0 ok, 2 usage,
  3 I/O, 4 invalid archive or integrity, 5 step budget, 6 overflow, 7 differs
  from the original.

  
Rust library


let archive = uorc::compress(&bytes, uorc::DEFAULT_STEPS)?;
let original = uorc::decompress(&archive, uorc::DEFAULT_DECODE_WORK)?;
assert_eq!(original, bytes);
let info = uorc::inspect(&archive)?;           // header + integrity, no decode
uorc::verify(&archive, Some(&bytes), uorc::DEFAULT_DECODE_WORK)?;
let many = uorc::compress_objects(&[a, b, c], uorc::DEFAULT_STEPS)?;
let parts = uorc::decompress_objects(&many, uorc::DEFAULT_DECODE_WORK)?;
// Or stream between any reader and writer, with bounded memory:
uorc::compress_stream(reader, writer, uorc::DEFAULT_STEPS, uorc::default_threads())?;

  
JavaScript (this page's module)


import { load } from "./uorc.js";
const uorc = await load("./uorc.wasm");
const archive = uorc.compress(new TextEncoder().encode("hello hello hello"));
const original = uorc.decompress(archive);
uorc.inspect(archive);                 // [{ representation, object_lengths, integrity_ok, ... }]
uorc.verify(archive, original);        // throws if it does not reproduce original
const bundle = uorc.compressFiles([{ path: "a.txt", data }, { path: "d", kind: "directory" }]);
const files = uorc.decompressFiles(bundle); // [{ path, kind, data }]
// Files of any size, one frame in memory at a time:
const blob = await uorc.compressBlob(file);
