# Official compiler-parsed diagnostic cache

These four JSON files are generated by `lexlean::sdk::read_module`, the official public SDK reader for authoring notation. They are read-only caches for matching source call signatures in another executor. The `.lex.tex` files remain byte-exact and authoritative. Nothing in the product build, compiler or runtime loads this cache as a semantic source.

The selected official compiler has no CLI subcommand for emitting this authoring JSON. Its supported SDK APIs are:

- `lexlean::sdk::read_module(&source)`: return the compiler-parsed module JSON, including executable, axiom and production fields.
- `lexlean::sdk::to_data_form(&source)`: return a LaTeX wrapper containing canonical `semanticdata` JSON. Language 1.2 refuses that data wrapper as production authoring source.

`tests/heap/export-semantic-json.rs` is a small read-only SDK adapter, not a parser implementation. It calls `read_module`, requires `write_module` to reconstruct the original notation byte-for-byte, and prints the returned JSON unchanged.

Using the selected official SDK's existing library build:

```sh
/absolute/official/rustc --edition=2021 tests/heap/export-semantic-json.rs \
  --extern lexlean=/absolute/official-sdk/deps/liblexlean-HASH.rlib \
  -L dependency=/absolute/official-sdk/deps \
  -o /tmp/uorc-export-semantic-json
/tmp/uorc-export-semantic-json src/Uorc/Core/RuntimeValue.lex.tex > /tmp/RuntimeValue.semantic.json
/tmp/uorc-export-semantic-json src/Uorc/Core/Heap.lex.tex > /tmp/Heap.semantic.json
/tmp/uorc-export-semantic-json src/Uorc/Core/RuntimeTable.lex.tex > /tmp/RuntimeTable.semantic.json
/tmp/uorc-export-semantic-json src/Uorc/Core/HeapAudit.lex.tex > /tmp/HeapAudit.semantic.json
```

`HASH` identifies the SDK build selected by its owner; it is not an alternative product dependency. No SDK implementation is copied into the compressor.

Each document has schema `lexlean/semantic-module/2` and the complete `declarations` array. Definitions retain `name`, `parameters`, `result`, `body`, `axioms`, `executable`, and any `production` or recursion metadata. Structure and inductive declarations retain their fields and constructors. The exact SDK schema is [`semantic-module-v2.schema.json`](https://github.com/UOR-Foundation/LexLean/blob/71defb4c663aaec5b9a3aab04cbc6a03e7106227/schemas/semantic-module-v2.schema.json).

`provenance.json` binds the source commit, every source and JSON SHA-256, adapter hash, exact official SDK source commit and binary/library hashes. Each module was exported twice with byte-identical results. Every definition has explicit executable and axiom fields; all SDK notation round trips were byte-exact. The four authoritative source files were hashed before and after export and did not change.

The known production preservation regression remains owned by LexLean #310 / PR #393. This cache neither circumvents that check nor changes its acceptance status.
