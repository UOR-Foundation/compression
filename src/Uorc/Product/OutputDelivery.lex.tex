It does not copy an Arena, read Heap nodes, execute an archive, or create verified/completed proof facts. Enclosing wire/admission/hash/caller-root controls stay caller-owned without an Arena and remain pinned while this envelope holds the actual Arena and Usage. Waiting, suspension, early source failure, stale delivery, callback rejection, missing observations and arithmetic failure retain the exact envelope. Successful folds move it once into a receipt.
