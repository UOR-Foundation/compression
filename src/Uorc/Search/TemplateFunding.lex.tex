definition{
  name: contract,
  parameters: [],
  result: String,
  body: "Each source step performs at most one bounded real TemplateStream operation. It retains partial shared RuntimeWork task payment without computing a future arena. Once the whole declared fee is paid, operational RuntimeResources.charge occurs before the actual source/sequence/heap call; arena ownership is observed afterward and all failures retain the resulting source state, arena, delta and committed usage. Excess offered credits are returned. The source local transition count, task-fee work and Heap.delta are distinct measures. Waiting and terminal polling perform no runtime callback. Task selection cannot silently move partial payment to another task. A production admission controller must still guard acknowledgment by actual fully completed RuntimeAdmissionCredit.awaiting and maintain owned control/payload/span roots. This adapter is operational, not canonical semantic cost evidence."
}
