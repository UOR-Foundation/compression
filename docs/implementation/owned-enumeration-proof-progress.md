## Word universe and real-machine boundary

The mathematical representation is a reversed finite list of byte digits.
Pointwise normalization changes a Nat payload modulo 256 while preserving each
existing list cell and exact length. It never strips leading/trailing zeros.
Every finite UInt8 list has an exact list inverse and length-preserving
embedding. Empty, `[0]`, `[0,0]` and every other all-zero length remain distinct.
The source supplies rank/decoder, successor, inverse and abstract coverage
proof programs over the full declared domains.

These programs do not yet establish forward-shortlex order equivalence or a
refinement of the actual arena/sequence/builder producer. Abstract coverage,
even if accepted, is not actual owned producer no-omission. The machine's
rightmost-pivot invariant, read-step byte adequacy, builder simulation,
reachable-arena/root-multiset validity, refusal/prepayment refinement and
successful byte-preserving installation remain open.

In the local laws, predecessor stability means the current handle and length,
not byte equality, liveness or preservation of the whole arena. The rejected
acknowledgment funding law applies to `fundObserved` after outer arena
observation; it is not a theorem about all outcomes of the full `fund` wrapper.
No production function is redirected to the pure mathematical helpers.
