# Closed typed frontend application

`Product.Application.run(Command) -> Frame` composes the actual Workspace and
Presentation functions in one generated constructor universe. Commands preserve
factory, bound user actions, narrowed picker/collection callbacks, runtime
notices, numeric edits, observation and final publication-permit queries.
`authority` distinguishes their trusted call roles. The generic persistent host
retains typed state under its opaque instance identity; arbitrary caller JSON or
state snapshots are not this interface.

Frame returns the complete state, generated View and effects, disposition and
message, source focus ID, Workspace retirement disposition and optional permit.
This avoids translating package-local state/View ADTs between separate frontend
exports. It changes no operation, label, enabled state, evidence boundary or
renderer behavior. Child runtime arenas, storage and outstanding I/O remain
separate actual owners; a frontend retirement request does not destroy them.

The exact initial source checkpoint is recorded in
`validation/product/application-evidence.json`. Its 12-module Product-only
closure passed full official diagnostic source/kernel/axiom verification (645
declarations), 15 typed VM flows and three actual source defects. An independent
SDK render compiled and executed 65 same-package create/present calls plus all
15 source control flows. That render is explicitly unqualified and carries no
certified-export, NativeLibrary, Wasm, browser or release claim.

The actual certified export command is `lexlean --diagnostic-format json
production build --request request.json` in the included exact diagnostic
project. The failing root is `Uorc.Uorc.Product.Application.run`, certificate B
for rust-std. The unchanged 4,194,304-byte guard refused a derivation lower bound
of 4,194,360 bytes. This is not its final certificate size or evidence that saving
56 bytes would suffice. No Core module or RuntimeByteBuilder appears in this
closure. Exact source/configuration/IR/type maps, failed result, compiler
identity and complete diagnostic inputs are included in its public archive.

One package establishes type compatibility only. A wide numeric edit in the
render probe returns outer Overflow without Frame. That test contains no Arena,
Delta or external I/O achievement, so it demonstrates no operational owner loss.
The actual complete operational root must retain achieved state and failure-owner
custody on every generated failure, or prove those exits unreachable under its
actual admission and checked arithmetic. Cloning a predecessor cannot recover
later effects. This obligation remains unqualified.

The receipt preserves the exact pre-shared-Control-updater source snapshot.
Subsequent factoring and export attempts have their own scope; this historical
receipt must not be attributed to a later complete source graph. Production locks,
all frontend variants/fields and the certificate guard remain intact.
