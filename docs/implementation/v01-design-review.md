# First-generation product design review

This is an implementation review, not a second specification or an acceptance
record. The LexLean graph rooted at `Uorc.Specification` and `Uorc.Registry`
owns product meaning and claim status. The current integration is incomplete;
the v0.1 tag is reserved for the complete, qualified product.

## One objective, several kinds of evidence

The object being optimized is the complete exact description: decoder program,
parameters, residuals, framing, and any declared basis dependency. A compact
model is useful only when its complete description beats another checked
description. A learned model, dictionary or shared object receives no free
bytes merely because discovery was sophisticated.

Size, decoding work, retained storage and discovery effort are distinct costs.
A chosen objective and admissible universe must be explicit before a minimum
certificate has meaning. Finite search produces a best checked incumbent, not
an unrestricted shortest-program theorem. Raw representation preserves the
ability to represent input; it does not promise every input gets smaller.

The evidence layers are deliberately separate:

- Mathematical reference semantics and general refinement properties.
- Source checking, exact axiom audits and compiler preservation evidence.
- Actual generated execution and independent full-byte reconstruction.
- Measured compression, work and physical resource observations.
- A scoped minimum certificate, when its checker has actually completed.

No hash agreement substitutes for comparing available original bytes. No
ordinary successful decode establishes an unavailable original's identity.
No logical arena weight is described as process RSS.

## Concrete lessons from the ecosystem

MNIST's source-owned quantized kernels, parameters and execution show how a
learned computation can have explicit semantics. They do not show that its
classification result encodes an arbitrary image. Compression must include the
exact reconstruction mechanism and any remaining information.

Rule30's small local rule and expanding execution separate description length
from reconstruction work. The same distinction applies to a synthesized
compression program: a short description does not make execution free, and
finite observations do not prove an unrestricted periodicity or randomness
claim.

Prism/LexLean and the template contribute source-owned behavior, claim
boundaries, generated realizations and tests that reject representative
defects. Their existence alone is not evidence that this product executes.
The actual source closure, compiler identity and generated artifact must be
bound to each result.

## Composition from bytes to experience

The production path is being connected through charged image spans, bounded
wire events, incremental typed admission, owned program metadata, execution,
ordered object boundaries and staged publication. Mathematical Graph/Rope
carriers remain useful references; retaining them as uncharged production
backing beside a handle arena would defeat ownership accounting.

Pending work and failure retain the achieved arena, resource counters and
temporary ownership tickets. Cancellation releases actual roots. A failed
multi-allocation update must not discard its partial allocation history and
pretend it rolled back. Last-use reclamation removes slot edges rather than
replacing released values with plausible defaults.

The user-facing model includes files and streams, ordered collections with
empty objects, progress, interruption, effort extension, resume, basis
handling, comparison and truthful evidence. Simple compression/decompression
must not require completing an optional minimum certificate or navigating a
proof dashboard. Inspection and advanced evidence remain useful operations
with their own clearly bounded meaning.

Output before final validation is staged, not a completed published file.
The host must distinguish successful commit, known non-publication and unknown
or partial publication. Stdout cannot be made reversible by terminology.
Operational storage/addressability limits are reported as resource outcomes,
not silently installed as mathematical format limits.

## Design corrections under implementation

- A dictionary with whole-byte indices cannot exploit a byte alphabet of
  2–128 symbols at one-byte index width. Bit-packed indices are being generated
  through the same closed decoder machinery, with dictionary, count and tail
  costs included.
- The initial 64-byte chained integrity construction pays substantial repeated
  framing work. A distinctly named streaming construction uses the underlying
  SHA-256 message-domain bound without retaining a whole segment or a
  whole-stream counter. Its security statement is a collision reduction and
  computational assumption, never global digest injectivity.
- Persistent-index logical weights do not settle physical sharing costs.
  Generated carrier and clone behavior require direct inspection and native
  measurement, including retained aliases and failed updates.
- Historical small hex transports and whole-buffer adapters are not the
  universal product's input domain. A versioned streaming host boundary is
  being qualified rather than claiming that an old bounded adapter already
  supplies it.

## Format and release discipline

Product generation, archive format and machine profile are separate identities.
The unavailable historical archive-v1/profile02 draft is not treated as a
source authority. Current format2/machine1 source is explicitly unshipped.
Replacing its integrity meaning requires an explicit new archive identity,
not a silent compatibility assertion. No existing shipped format is being
rewritten.

All capabilities remain in first-generation scope. Open refinement, ownership,
certificate, native/browser, corpus and acceptance work is unfinished work,
not a later-generation roadmap. Locks and universal safeguards remain intact;
diagnostic subsets cannot set release acceptance. Real poor compression or
incomplete resource-limited runs remain reportable evidence rather than
reasons to alter a sealed benchmark after seeing its result.
