# Planning

Implementation planning is tracked in the GitHub issues for
`UOR-Foundation/compression`.

This directory is not UORC semantic or claim authority. Product scope, claim
boundaries, source ownership, and research positioning are authored in
`src/Uorc/Specification.lex.tex` and `src/Uorc/Registry.lex.tex`; committed
model and project-documentation files are generated projections of that graph.

Governance evidence belongs under `docs/governance/`. The inherited repository
policy remains in the template-owned root policy files.
